# Salon Locator ✂️

An Android app I built as part of my college coursework using Kotlin and Android Studio.

The app lets users manage salon records and organise them using personal ratings, sorting and filtering.

## Features

- View salons in a list.
- Open a salon record for editing.
- Delete a salon with a confirmation prompt.
- Sort salons alphabetically or by highest rating.
- Filter the list to show salons rated 4 or above.

## Built with

- Kotlin
- Android Studio
- Android XML layouts
- RecyclerView
- Gradle

## Running the app

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Let Gradle sync and install any requested SDK components.
4. Run the app on an Android emulator or connected device.
